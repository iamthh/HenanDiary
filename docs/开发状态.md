## M0 交付物

**工程骨架**：`pyproject.toml`（uv 管理，6 个运行时依赖 + pytest）、`.gitignore`、`README.md`、
`main.py`、`config.py`、`logger.py`，以及 `collector/` `ai/` `storage/` `report/` `scheduler/` `ui/`
六个包（`ui/` 仅占位，M0 不引入 PySide6）。

**已冻结的接口**：

- `storage/db.py`：4 张表 DDL + 8 个函数签名（`init_db`、`save_screenshot_analysis`、
  `get_today_analyses`、`save_daily_report`、`get_daily_report`、`save_weekly_report`、
  `get_pending_reports`、`cleanup_old_data`）。实现体一律 `NotImplementedError`，
  由 M1 / M2 / M5 / M6 按归属补，签名不得私改。
- `config.py`：`%APPDATA%\DailyLog\` 数据目录解析 + settings.json 读写
  （`load_settings` / `save_settings` / `update_settings` / `ensure_dirs` 已可直接调用）。
- `logger.py`：`get_logger(name)` 统一入口，1MB × 5 轮转写 `logs/app.log`。
- `storage/cleanup.py`：`cleanup_expired(retention_days)` 签名，M6 实现。

**验证结果**：`pytest` 50 项全绿。其中 `tests/test_storage/test_db.py` 为接口契约测试，
M1 补上 `init_db` 实现后需删除 `test_interfaces_are_not_implemented_yet` 一项，
其余签名与建表断言继续生效。

## 已确认的关键决策

- 纯截图驱动，不做窗口追踪
- 截图纯内存处理，绝不写盘
- 截图间隔 10/5/2 分钟可选，默认 5 分钟
- 日报 22:00 生成，次日 00:30 覆盖
- 周报周日 22:30 生成
- 数据存 `%APPDATA%`，原始数据保留 3 天
- 用户自备 API Key，无服务端
