- 新增私有方法 `_stream_text(messages, max_tokens)`：以 `stream=True` 拉取分片并拼接正文；
  跳过只带 usage、`choices` 为空的收尾分片，忽略 `delta.content` 为 None 的分片

- **原因**：千问 Qwen-Omni 系列官方要求 `stream=True`（否则直接报错），QVQ 系列「仅支持流式输出」；
  VL 系列与 OpenAI 官方模型同样兼容流式，所以统一成一条路，不必按模型维护两套
- 配套新增 `tests/test_ai/test_client.py`（8 项）：流式拼接、边界分片、DPAPI 加解密往返、
  未配 Key 抛 RuntimeError——此前 `ai/client.py` 一直没有独立测试文件

**验收**：`pytest` **144 项全绿**（改前 136 项）。
